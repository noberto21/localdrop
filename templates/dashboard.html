Phone cannot connect?
  • Both devices must be on the same Wi-Fi. Guest networks and “client isolation” block this.
  • Windows Firewall: allow Python on Private networks (Windows asks the first time), and set your Wi-Fi to the Private profile.
  • If the Wi-Fi has no internet, turn off mobile data on the phone so it does not bypass the Wi-Fi.
  • Turn off VPNs on both devices. See README.md for details.
